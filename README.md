# Мёртвый туман — исходники

Запуск без сборки: откройте `index.html` в браузере (обычные скрипты, сервер не нужен).
Один файл для публикации/отправки: `python3 build.py` -> `dist/dead-fog.html`.

## Структура
- `css/style.css` — стили HUD и меню.
- `libs/` — three.js r128, GLTFLoader, SkeletonUtils (не менять).
- `js/` — игра. Файлы подключаются в порядке номеров (общий глобальный scope, порядок важен):
  - `01-state.js` — оружие (WEAP), улучшения, состояние игрока S/P, константы
  - `02-scene-collision.js` — сцена, свет, пол/небо, модели оружия в руках, коллизии
  - `03-enemies-base.js` — базовые враги (старый код), убийство, частицы
  - `04-audio.js` — звук и музыка (WebAudio)
  - `05-combat.js` — стрельба, трассеры
  - `06-mobs-flashlight.js` — виды мобов, снаряды, подсветка последних мобов, фонарик
  - `07-voices-detail-weapons.js` — крики мобов, колесо смены оружия
  - `08-gear-bestiary-drops.js` — обвесы, мастерская, гранаты, ПНВ, дроп, бестиарий
  - `09-maps-bosses.js` — 6 локаций, текстуры, ИИ боссов, обстрелы
  - `10-mob-models.js` — процедурные модели мобов, анимации
  - `11-dev-window.js` — окно разработчика (тильда x3)
  - `12-glb-models.js` — загрузка своих .glb, 3D босс-бар
  - `13-waves-save-ui.js` — волны, сохранения, меню, ввод
  - `14-main-loop.js` — главный цикл и запуск

## Свои модели
Тильда 3 раза -> «Модели .glb» -> «Загрузить .glb» для нужного монстра.
